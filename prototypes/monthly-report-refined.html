구현 개요
· PPT: pptxgenjs 라이브러리 (이미 앱에 로드됨) - 슬라이드 자동 생성, 차트는 Plotly SVG 캡처 or pptxgen 네이티브 차트
· xlsx: xlsx-js-style 라이브러리 (이미 로드됨) - 시트별 데이터, 셀 서식(색상, 굵기, 병합)
· 데이터 소스: Supabase hosp_settlement (매출) · KOS API (예약/환자) · gsheet-bridge (재고)
· 자동 발송: 매월 1일 오전 9시 스케줄러로 PPT + xlsx 둘 다 생성해 이메일 첨부
