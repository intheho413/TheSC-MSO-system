예약 인사이트: A3 (아코디언) + A2 (별도 탭 상세)
→ 대시보드에 접기/펼치기 섹션 구조 → 관심 영역만 열어봄. 상세 분석은 별도 "예약 인사이트" 탭에서.
→ 3가지 뷰 토글(A4)은 사용자마다 취향 갈릴 수 있어 초기엔 skip 권장.

월간 리포트: B3 (Google Sheets 자동 생성) + B4 (일별 카톡 요약)
→ 팀 문화가 이미 Google Sheets 기반이라 B3이 최적. 리포트 파일이 다른 재고/정산 시트와 같은 폴더에 축적.
→ 원장/실장이 매일 카톡으로 어제 요약을 받으면 앱 접속 없이 상황 파악 가능. 앱은 상세 조회용으로만 사용.

왜 이 조합?
1. 일상 조회: 매일 카톡으로 요약 → 이상 있을 때만 앱 접속
2. 앱 조회: 아코디언으로 관심 섹션만 펼침 → 정보 과부하 없음
3. 월말 리포트: 버튼 한 번으로 Sheets 생성 → 팀 공유
4. 심층 분석: 별도 예약 인사이트 탭 (필요시)

다른 조합도 가능합니다. 선호 시안(예: A3+B3, A2+B2, A4+B4 등) 알려주시면 그대로 진행하겠습니다.
